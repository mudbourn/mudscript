Console — use with care

This console runs arbitrary Lua on your machine with the same access mudscript itself has — your files, input, and windows.

Never paste code you didn't write or don't fully understand. A snippet someone hands you can look harmless and still delete files, log your keystrokes, or take over your session. If you can't say exactly what a line does, don't run it here.
